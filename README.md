# 정산 규정·금액 검증기

출장·초과근무·특근매식비의 **규정상 지급대상과 기대금액을 다시 계산해 실제 정산액과 비교**하고, 수식 누락·값 덮어쓰기·수식 패턴 이상을 보조 점검하는 오프라인 브라우저 앱입니다.

**웹 실행 주소:** https://settlement-checker-mocha.vercel.app/

## 실행 방법

1. `index.html`을 Chrome 또는 Edge로 엽니다.
2. 슬라이드 탭에서 `특근매식비 정산` 또는 `출장비 정산`을 선택하고 해당 정산 엑셀을 불러옵니다.
3. 시트, 제목 행, 첫 데이터 행, 행 식별 열을 확인합니다.
4. 출장비는 `근무지 내·외 함께 / 근무지 내만 / 근무지 외만` 범위를 선택합니다. 연결된 열과 검사 기준을 확인하고 **정산 검사하기**를 누릅니다.
5. 결과의 권장 수정 내용을 검토하고 수정할 항목을 선택합니다.
6. **선택 항목 수정본 엑셀 저장**을 눌러 원본과 별도의 수정본을 받습니다.
7. 필요하면 검증 결과를 CSV로 저장합니다.

각 탭의 **샘플 받기** 버튼으로 개인정보가 없는 교육용 엑셀을 생성해 시험할 수 있습니다. GitHub 공개 저장소에는 정산 엑셀 파일을 올리지 않습니다.

인터넷 연결이나 별도 설치가 필요하지 않습니다. 엑셀 파일은 브라우저 메모리에서만 읽으며 외부 서버로 전송하지 않습니다.

### 정산 유형별 검사

- **특근매식비:** 인정시간, 출장 식비 지급 여부, 특근매식비 실제액 및 시간·단가 설정만 표시합니다. 공용차량과 출장시간 설정은 숨기고 검사에서도 제외합니다.
- **출장비:** 근무지 내·외를 행별로 구분하고, 내·외 함께 또는 한 구분만 검사할 수 있습니다. 근무지 내는 시간별 정액·1만원 감액을, 근무지 외는 일비·식비·숙박비·운임을 별도로 검증합니다. 특근매식비 검사는 실행하지 않습니다.
- 파일 열 제목으로 정산 유형을 자동 추천합니다. 탭을 직접 선택한 경우 선택을 유지합니다. 탭을 바꾸면 이전 검사 결과는 지우고 다시 검사합니다.
- 검사할 수식 열도 유형에 맞춰 추립니다. 새 파일이나 다른 시트를 열면 열 연결을 다시 탐지하여 이전 파일의 열 번호가 섞이지 않게 합니다.
- 샘플 파일 받기는 현재 탭에 맞는 파일을 생성합니다. CSV에는 정산 유형도 기록합니다.
- 모든 지급 예외·교통수단별 적정성·증빙의 진위를 자동 검증한다고 보장하지 않습니다. 불명확한 값은 규정 오류와 구분하여 `자료 확인 필요`로 표시하고 자동 수정하지 않습니다.

### 근무지 외 출장 금액 검증

한 행은 한 출장의 합계이며, 숙박지역은 동일 지역 기준으로 입력합니다.

| 항목 | 입력자료 및 계산 기준 |
|---|---|
| 지급등급 | 여비등급 열의 제1호·제2호. 열이 없으면 화면에서 공통 등급을 명시적으로 선택해야 함 |
| 출장일수·숙박일수 | 각각 정수. 당일 출장도 숙박일수 0을 입력 |
| 일비 | 기본 25,000원 × 출장일수. 공용차량 이용일의 일비만 50% 지급. 여러 날 이용 시 실제 이용일수 필요 |
| 식비 | 기본 25,000원 × 출장일수 − 담당자가 확인한 식비 공제액. 공제가 없으면 0을 명시 |
| 숙박비 | 밤별 증빙액을 입력(예: `95000;80000`). 제2호는 밤별 서울 100,000원·광역시 80,000원·기타 70,000원 상한 적용. 일반 제1호는 증빙 실비 비교 |
| 운임 | 담당자가 교통수단·등급·할인·자가용 예외 등을 검토한 `운임 증빙 인정액`과 실제 지급액을 비교. 운임이 없으면 두 열 모두 0을 명시 |
| 총 정산액 | 현재 운임·일비·식비·숙박비 지급액 간의 산술 합계 확인. 각 항목을 먼저 수정하고 Excel에서 다시 계산 |

규정 근거는 제16조제1항·제3항·제4항·제5항, 제8조의2, 제9조부터 제13조까지 및 별표 2 등으로 표시하며 원문 페이지로 연결됩니다. 15일 초과 출장, 혼합 숙박지역, 증빙 누락, 예외·특례사항은 자동 확정하지 않습니다. 수로·항공여행 중 식비·숙박비 등 특례는 예외사항에 기록하고 별도 검토하세요.

테마는 선택한 정산 유형에 따라 전환됩니다. **특근매식비**는 기존 Rosé Pine Dawn 배경 `#FAF4ED`와 로즈색 버튼을 유지하고, **출장비**는 Osaka Jade 라이트 배경 `#F6F5DD`·카드 `#E8E7CC`·입력창 `#D5D4B8`·녹색 버튼 `#3D7A52`·옥색 강조 `#1FAA90`를 사용합니다. 결과표·원문 팝업도 선택한 테마를 따르며 원문 이미지 자체의 색상은 변경하지 않습니다.

버튼을 누르면 여러 장의 문서 카드가 좌우로 흩어진 뒤 천천히 아래로 떨어지는 애니메이션과 브라우저에서 직접 생성한 짧은 효과음이 재생됩니다. 운영체제에서 동작 줄이기를 설정한 경우 애니메이션은 자동으로 생략됩니다.

상단 앱 제목은 Windows의 `HYHeadLine-Medium`, 큰 제목 `정산 검증기`는 더 굵은 `HYGothic-Extra` 글꼴을 사용하며, 글꼴이 없는 환경에서는 맑은 고딕으로 대체됩니다.

큰 제목 `정산 검증기` 옆에는 투명 배경으로 분리된 업무 담당자 캐릭터가 배치됩니다.

검사 버튼을 누르면 버튼 위에 안경 쓴 캐릭터가 즉시 80% 크기로 나타나 빠르게 커집니다. 효과는 1.5초간 지속되고, 효과 시작 후 0.85초부터 캐릭터가 완전히 사라지기 전에 결과 영역으로 자동 이동합니다. 버튼 옆 고정 이미지는 표시하지 않습니다. 동작 줄이기 환경에서는 확대 없이 사라지는 효과만 적용합니다.

상단의 **어떤 근거규정이 사용되었나요?** 버튼에 마우스를 올리거나 클릭하면 근거 규정 목록이 표시됩니다. 목록의 `저장 원문`을 누르면 오프라인 원문 팝업을 엽니다. 커서를 다른 위치로 옮기면 작은 안내창은 자동으로 닫힙니다.

## 검사 기준

- **특근매식비 금액:** 인정시간, 출장 식비 중복 여부와 설정 단가를 이용해 기대금액 계산
- **근무지 내 출장여비:** 출장시간에 따른 설정 금액과 실제 정산액 비교
- **근무지 외 출장여비:** 일비·식비·숙박비·운임을 각각 비교하고 공용차량 이용일수에 따른 일비 50% 지급을 적용
- **오류 설명:** 실제액·기대액·차액, 틀린 이유와 적용 규정의 세부 기준 표시
- **근거 위치:** 출장여비는 「공무원 여비 규정」 제18조제1항 본문(시간별 지급액) 및 단서(공용차량 감액)를 표시합니다. 특근매식비는 2026년도 집행지침 제2편 Ⅲ. 비목별 지침의 1. 운영비 → 1-5. 특근매식비(210-05목) → 가. 지급대상자 / 나. 지급단가 및 집행방법을 표시합니다. 수식 자체 점검에는 법령 조항을 부여하지 않습니다. 해당 근거 위치는 CSV에도 저장됩니다.
- **원문 팝업:** 검사 결과의 조·항 또는 지침 항목을 누르면 사용자가 첨부한 실제 규정의 해당 페이지를 오프라인으로 엽니다. 기본 화면은 원문 페이지 이미지이고, `전체 PDF 보기` 또는 `저장된 전체 PDF를 새 창에서 열기`로 문서 전체도 확인합니다. 모든 원문 파일은 앱 폴더에 저장되어 인터넷 연결이 필요하지 않습니다. 닫기 버튼, Esc 또는 팝업 바깥 클릭으로 닫습니다.

### 저장된 규정 원문

`복무규정` 폴더의 HWP·HWPX 8개를 보존하고, `복무규정/원문PDF`에 PDF 사본을 저장합니다. `복무규정/페이지`에는 해당 조항 주변 페이지의 PNG 사본을 저장합니다. 파일의 변환·저장은 규정 내용의 개정이나 앱 판정 기준의 자동 갱신을 의미하지 않습니다.

- 공무원 여비 규정(제36728호, 2026.10.2.): 제18조는 PDF 3쪽
- 2026년도 예산 및 기금운용계획 집행지침: 특근매식비는 PDF 164쪽(책자 154쪽)
- 공무원보수 등의 업무지침(인사혁신처예규 제226호): 근무지 내 국내출장은 PDF 602쪽(책자 601쪽)
- 공무원 여비 규정의 별표 1·2·4·5·9

앱을 다른 PC로 옮길 때는 `regulation-documents.js`와 `복무규정` 폴더도 함께 복사하세요. 브라우저의 PDF 뷰어를 사용할 수 없는 경우에도 기본 페이지 이미지는 표시됩니다.
- **수식 누락:** 식별값이 있는 데이터 행의 계산 셀이 비어 있음
- **값 직접 입력:** 수식 열에 수식 대신 숫자나 문자가 입력됨
- **수식 패턴 이상:** 같은 열의 다수 수식과 상대 참조 구조가 다름
- **잘못된 참조:** 수식에 `#REF!`가 포함됨

빈 데이터 행은 검사에서 제외합니다. 결과는 원본을 변경하지 않고 별도 CSV로 저장합니다.

## 수정본 생성

- 수식 누락·값 덮어쓰기·패턴 이상은 같은 열의 다수 정상 수식을 해당 행에 맞게 변환해 복원합니다.
- 규정·금액 오류는 표시된 기대금액을 입력합니다.
- 같은 셀에 수식 복원과 규정 금액 입력이 함께 선택되면 규정상 기대금액을 우선합니다. 알려진 금액 오류를 남긴 채 수식만 복원하는 선택은 차단합니다.
- 구성항목을 수정한 뒤 합계 수식은 Excel에서 재계산해 확인해야 합니다.
- 네 지급항목이 연속 열이고 총액이 해당 범위의 단순 `SUM` 수식인 경우, 수정본의 합계 저장값도 갱신합니다. 임의 수식이나 수기 입력된 총액은 별도로 재확인해야 합니다.
- 인정시간 또는 원자료가 불명확한 항목은 자동 수정하지 않습니다.
- 원본 파일은 변경하지 않고 파일명 끝에 `_수정본`을 붙여 저장합니다.

## 중요 사항

- 본 앱은 수식 구조를 검사하며 Excel 수식을 직접 재계산하지 않습니다.
- 검사 결과는 지급 여부를 자동 결정하지 않습니다.
- 확인 대상으로 표시된 셀은 원자료와 공무원 초과근무·특근매식비 지급 규정에 따라 담당자가 최종 판단해야 합니다.
- 실제 업무 파일을 사용하기 전에 백업본 또는 사본으로 충분히 시험하세요.

## Vercel 배포

프레임워크와 빌드 과정이 없는 정적 HTML 앱으로 배포합니다. `vercel.json`에 설정이 포함되어 있으며, `.vercelignore`는 실행 파일과 공개 규정 사본만 배포하도록 제한합니다. `.vercel` 연결 설정과 로그인 정보는 GitHub 및 웹 배포에 포함하지 않습니다.

배포 시에는 GitHub의 `main`을 깨끗한 폴더에 복제해 사용했습니다. 현재 프로덕션 사이트는 Vercel CLI로 배포되어 있습니다. GitHub 푸시 시 자동 배포하는 Git 연동은 GitHub/Vercel 접근 권한을 추가 연결해야 합니다.

```powershell
vercel login
vercel deploy --prod --yes --project settlement-checker --scope kuri16
```

웹사이트를 방문하면 HTML·JS·이미지·규정 사본을 내려받지만, 선택한 정산 엑셀의 검사·수정은 브라우저 안에서 처리합니다. 사이트 접속과 웹 리소스 로딩에는 인터넷이 필요하며, 인터넷이 없는 PC에서는 저장소 전체를 다운로드해 `index.html`로 실행하세요.
